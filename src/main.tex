\begin{abstract}
    % TODO --- write after all sections are drafted.

    %
    % Draft placeholder:
    Coordinating traffic signal agents in multi-agent reinforcement learning
    (MARL) requires partitioning intersections into coordination groups, yet
    existing partitions use road topology rather than vehicle flow structure.
    We develop a retention-based theory of partition quality that answers
    \emph{what a partition should preserve} and \emph{why flow is a valid
        training-free surrogate}. The theory is a three-link chain: (i)~the map
    equation's inter-module codelength term equals one minus the flow retention
    $\Phi$ exactly, so InfoMap maximises an entropy-regularised flow retention;
    (ii)~under flow-local traffic dynamics, flow cut by a partition upper-bounds
    the inter-agent statistical dependency it cuts; and (iii)~under networked-MARL
    locality assumptions, cut dependency upper-bounds the value loss of regional
    decomposition. Minimising the map equation therefore minimises an upper bound
    on the value loss of regional MARL. We operationalise the chain with the
    \emph{dependency retention ratio}~$\Psi$, computed primarily from a
    model-free mutual-information instrument and, where the coordination
    mechanism admits it, from Jacobian-based instruments on trained critics and
    attention models. Across two SUMO road networks (Cologne8, Ingolstadt21),
    three stochastic seeds, and every matched module count tested, InfoMap
    retains more flow ($\Phi$) and more state mutual information ($\Psi$) than
    same-size METIS partitions --- an ordering the map-equation identity
    predicts and that holds in all 12 same-$k$ comparisons, the paper's
    confirmatory core. This retention advantage coincides with large
    single-seed reductions in average waiting time under regional reward
    sharing (IPPO) and a regional centralised critic (MAPPO), up to
    $2.85\times$ on a 21-intersection network; a case study with regional
    graph attention (CoLight) instead locates the predicted phase boundary at
    which attention masking, not flow-coherent partitioning, becomes the
    binding constraint once modules fall below about four agents. We report
    the dependency-retention result across seeds and the training result as a
    single-seed case study pending multi-seed confirmation, and we state this
    evidentiary split explicitly rather than letting the strength of one link
    stand in for the other.
\end{abstract}

\section{Background}
\label{sec:background}

\subsection{Network-Distributed POMDP and the Coordination Graph}
\label{sec:ndpomdp}

Each signalised intersection $i \in \mathcal{V}$ observes a local state
$o_i$ (queue lengths, current phase, elapsed phase time) and selects a
phase action $a_i \in \mathcal{A}_i$.
We model the joint problem as a \emph{network-distributed POMDP} (ND-POMDP),
in which a coordination graph $\mathcal{G}_C = (\mathcal{V}, \mathcal{E}_C)$
encodes which agent pairs share explicit interaction terms in the joint reward.
Three structural properties of TSC motivate this formulation.

\textbf{(a) Reward locality with spill-back coupling.}
The immediate reward $r_i$ depends primarily on queues and delays at
intersection $i$, making it nearly local.
However, when downstream lanes saturate, backward-propagating queue waves
couple $r_i$ to the actions at neighbouring intersection $j$ via
spill-back~\citep{dependencydyn2025}.
The ND-POMDP captures this through interaction terms:
\begin{equation}
    R(\mathbf{a})
    \;=\; \sum_{i \in \mathcal{V}} r_i(o_i, a_i)
    \;+\; \sum_{(i,j)\in\mathcal{E}_C} r_{ij}(o_i, o_j, a_i, a_j).
    \label{eq:ndpomdp}
\end{equation}
Edges in $\mathcal{G}_C$ mark pairs where the cross-agent term $r_{ij}$ is
non-negligible; omitting a spill-back edge misattributes joint outcomes to
independent agents.

\textbf{(b) Tractability via maximum clique size.}
Exact coordination over a clique of $\omega$ agents requires evaluating
$|\mathcal{A}|^\omega$ joint actions.
Partitioning $\mathcal{V}$ into modules of bounded size
$|M_k| \leq \omega_{\max}$ keeps this tractable; in TSC networks
$\omega_{\max} = 4$--$6$ is sufficient in practice.

\textbf{(c) $\mathcal{G}_C$ is a free design variable.}
Unlike environments where the coordination graph is determined by the physics,
in TSC the coordination modules are explicitly constructed before training.
This makes partition selection the central algorithmic question: which graph
minimises the coordination cost severed by module boundaries?
Attribute~(a) answers what ``coordination cost'' means: the mass of spill-back
interaction terms $r_{ij}$ cut by the partition.
Attributes~(a)--(c) together motivate using OD vehicle flow as the partition
criterion, and Section~\ref{sec:infomap} makes this precise.

\subsection{The Map Equation}
\label{sec:mapeq}

InfoMap~\citep{rosvall2008maps,rosvall2009mapequation} finds a partition by
minimising the description length of a random walk on a weighted directed graph:
\begin{equation}
    L(\mathcal{M})
    \;=\; q_{\circlearrowleft} H(\mathcal{Q})
    \;+\; \sum_{k=1}^{K} p_k^{\circlearrowleft} H(\mathcal{P}_k),
    \label{eq:mapeq}
\end{equation}
where $q_{\circlearrowleft}$ is the aggregate rate of inter-module random-walk
transitions, $H(\mathcal{Q})$ is the entropy of the between-module codebook,
$p_k^{\circlearrowleft}$ is the within-module random-walk rate for $M_k$, and
$H(\mathcal{P}_k)$ is the within-module codebook entropy.
Minimising $L(\mathcal{M})$ minimises the average bits required to describe
the walker's trajectory, which is achieved by grouping nodes that exchange the
most flow into the same module --- so that the walker rarely crosses module
boundaries and the between-module term $q_{\circlearrowleft}H(\mathcal{Q})$
stays small.

Applied to $\mathcal{G}_{\mathrm{OD}}$, InfoMap groups intersections that
exchange the most vehicle volume.
As we show in Section~\ref{sec:theory}, these are exactly the pairs most
likely to be coordination-necessary via spill-back, connecting the
information-theoretic objective of Eq.~\eqref{eq:mapeq} to the traffic-theoretic
requirement of Eq.~\eqref{eq:ndpomdp}.

The map equation belongs to the family of \emph{flow-based} partition
objectives, which evaluate a partition by the behaviour of a dynamical process
on the network, in contrast to \emph{combinatorial} objectives such as
minimum cut or balanced edge cut (METIS) that count edges irrespective of the
flow they carry.
Markov stability~\citep{delvenne2010stability,lambiotte2014multiscale} makes
this distinction canonical: flow-based objectives reward partitions in which a
random walker remains in the same module across consecutive steps, so a
flow-based and a combinatorial partition of the same network are categorically
different objects even when they look superficially similar.
Unlike modularity maximisation~\citep{newmangirvan2004}, the map equation does
not inherit modularity's resolution limit, although it is not scale-free
either: it has known field-of-view limitations and can over-partition
constrained, grid-like networks~\citep{edler2023community}.
Infomap itself is a greedy stochastic search over an NP-hard landscape and
does not guarantee the global codelength optimum~\citep{edler2023community}.

\section{Flow-Coherent Dependency Partitioning}
\label{sec:method}

\subsection{OD Flow Graph Construction}
\label{sec:odgraph}

We model the traffic network as a directed weighted graph
$\mathcal{G}_{\mathrm{OD}} = (\mathcal{V}, \mathcal{E}, \mathbf{W})$,
where $\mathcal{V}$ is the set of $N$ signalised intersections and $W_{ij} \geq 0$
is the observed vehicle count travelling from intersection $i$ to intersection $j$
over a representative time window.
We construct $\mathbf{W}$ from simulation trip logs: for each completed vehicle
trip, the sequence of intersections visited is recorded and the corresponding
directed edge weights incremented.
A warm-up period of approximately one hour under a uniformly random policy provides
a flow snapshot that reflects network demand structure prior to any learned behaviour.

The key inductive bias is that $\mathbf{W}$ captures \emph{demand} rather than
\emph{road topology}: two intersections connected by a high-volume corridor appear
as a strong edge regardless of their hop distance on the road graph.
This is what separates OD-flow partitioning from METIS on the adjacency matrix
and from Laplacian spectral methods~\citep{laplacian2009ieee}: both of the latter
assign edge weight by physical connectivity, not by how many vehicles actually
travel between node pairs.

\subsection{InfoMap Partitioning and Flow Retention}
\label{sec:infomap}
\label{sec:theory}

Given $\mathcal{G}_{\mathrm{OD}}$, we apply the Infomap
algorithm~\citep{rosvall2008maps,rosvall2009mapequation} to obtain a partition
$\mathcal{M} = \{M_1, \ldots, M_K\}$ by minimising the map equation of
Eq.~\eqref{eq:mapeq}.
Our theoretical account of \emph{why} this is the right objective is a
three-link chain, developed in this and the following two subsections:
the map equation is an exact statement about the flow a partition retains
(Proposition~\ref{prop:phi}); under flow-local traffic dynamics, retained flow
bounds retained inter-agent dependency (Proposition~\ref{prop:transfer});
and retained dependency bounds the value loss of regional MARL
(Theorem~\ref{thm:valueloss}).
The empirical program of Section~\ref{sec:experiments} then estimates the
constants of these bounds rather than gating on binary hypothesis tests.

\paragraph{Flow retention.}
For a partition $\mathcal{P} = \{P_1, \ldots, P_K\}$ with module assignment
$c(\cdot)$ and OD flow matrix $\mathbf{W}$, define the \emph{flow retention
    ratio}
\begin{equation}
    \Phi(\mathcal{P}, \mathbf{W})
    = \frac{\displaystyle\sum_{k}\sum_{i,j \,\in\, P_k} W_{ij}}
    {\displaystyle\sum_{i,j} W_{ij}},
    \label{eq:phi}
\end{equation}
the fraction of observed vehicle movements that stay within module boundaries.

\begin{proposition}[Flow retention is the map equation's inter-module rate]
    \label{prop:phi}
    Let the random walk in Eq.~\eqref{eq:mapeq} be the empirical OD walk:
    visit rates $p_i = \sum_j W_{ij} / \sum_{a,b} W_{ab}$ and transition
    probabilities $p_{ij} = W_{ij} / \sum_{j'} W_{ij'}$, so that the stationary
    edge measure is $p_i\, p_{ij} = W_{ij} / \sum_{a,b} W_{ab}$.
    Then the aggregate inter-module transition rate in Eq.~\eqref{eq:mapeq}
    satisfies
    \begin{equation}
        q_{\circlearrowleft}
        \;=\; \sum_{k} \sum_{i \in P_k}\sum_{j \notin P_k} p_i\, p_{ij}
        \;=\; \frac{\sum_{i,j:\, c(i) \neq c(j)} W_{ij}}{\sum_{i,j} W_{ij}}
        \;=\; 1 - \Phi(\mathcal{P}, \mathbf{W}).
        \label{eq:qphi}
    \end{equation}
\end{proposition}

\begin{proof}
    Substitute the empirical edge measure into the definition of
    $q_{\circlearrowleft}$ as the total stationary probability of inter-module
    steps~\citep[cf.][]{edler2023community} and sum over all ordered pairs with
    $c(i) \neq c(j)$; the last equality is the complement of
    Eq.~\eqref{eq:phi}.
\end{proof}

$\Phi$ is therefore not a heuristic proxy loosely associated with the map
equation: it \emph{is} the map equation's between-module rate, exactly, under
the walk model induced by the observed OD flows.

\begin{corollary}[InfoMap maximises entropy-regularised flow retention]
    \label{cor:regularised}
    Writing Eq.~\eqref{eq:mapeq} as
    $L(\mathcal{M}) = (1 - \Phi)\, H(\mathcal{Q})
        + \sum_{k} p_k^{\circlearrowleft} H(\mathcal{P}_k)$,
    the map equation is, at any fixed module-usage profile (fixed codebook
    entropies and within-module rates), monotone increasing in $1 - \Phi$.
    Minimising $L(\mathcal{M})$ thus maximises an \emph{entropy-regularised}
    flow retention: the codebook-entropy terms are the regulariser that rules
    out the degenerate all-in-one-module solution, which attains $\Phi = 1$
    but pays the full within-module description cost.
\end{corollary}

\paragraph{Information-theoretic reading.}
By Proposition~\ref{prop:phi}, $1 - \Phi$ is the per-step probability that the
coarse-grained state --- the walker's module label $m(t)$ --- changes.
A low inter-module rate means the module-label sequence is highly compressible,
i.e.\ the coarse-grained dynamics are maximally predictable.
Up to the null-model term, this is the one-step clustered autocovariance that
Markov stability maximises~\citep{delvenne2010stability,lambiotte2014multiscale}:
the probability that a walker occupies the same community at $t$ and $t{+}1$.
Equivalently, a partition with a low exit rate makes the chain nearly lumpable,
so InfoMap can be read as finding the coarse-graining of the OD walk that
loses the least description length.
In the ND-POMDP interpretation of Section~\ref{sec:ndpomdp}, minimising
cross-module walk rate is minimising cross-module coordination overhead while
maximising within-module coordination coherence.

\paragraph{What the empirical $\Phi$ comparison adds.}
Proposition~\ref{prop:phi} makes
$\Phi(\mathcal{P}_{\mathrm{InfoMap}}) \geq \Phi(\mathcal{P}_{\mathrm{METIS}})$
at matched module count a theorem-shaped expectation rather than an empirical
surprise.
Measuring it on real OD data (Section~\ref{sec:experiments}) remains
informative for two reasons.
First, real trips are path-dependent, so the memoryless-walk model behind
Eq.~\eqref{eq:mapeq} approximates actual routing; the higher-order map
equation is the standard refinement~\citep{rosvall2014memory}.
Second, Infomap's greedy stochastic search does not guarantee the global
codelength optimum~\citep{edler2023community}.
The observed margins quantify how much of the identity survives both gaps.

\subsection{Spatial Dependency Instruments and $\Psi$}
\label{sec:psi}

To measure how much dependency a partition retains, we need per-pair dependency
weights $D_{ij}$ that (i)~are computable without presupposing the partition,
(ii)~yield a scalar per pair $(i,j)$, and (iii)~can be aggregated into a
partition-level score. We introduce three complementary instruments, each matched
to the coordination mechanism at a given coupling level.

\paragraph{Physical dependency (model-free).}
The mutual information between agent state observations supplies a model-free
dependency weight:
\begin{equation}
    D^{\mathrm{MI}}_{ij}
    = \hat{I}\!\left(X_i(t);\, X_j(t{+}\tau)\right)
    \label{eq:dmi}
\end{equation}
estimated by the KSG $k$-nearest-neighbour estimator~\citep{kraskov2004ksg}
from warm-up trajectories.
$D^{\mathrm{MI}}_{ij}$ is model-free and applicable at L1: at the reward
coupling level (IPPO/IDQN), agents act independently and there is no
cross-agent input path in the policy network, making Jacobian-based measures
structurally inapplicable.
Spatial MI dominance in TSC networks is established by~\citet{stmarl2020},
and its mechanistic link to spill-back is established by~\citet{dependencydyn2025},
grounding $D^{\mathrm{MI}}$ as the natural physical dependency measure.

\paragraph{Learned dependency (Jacobian on the global model).}
For models that receive cross-agent inputs, we adapt the Jacobian influence
framework of~\citet{lrd2025} to the MARL dependency measurement setting.
For a model $F$ trained \emph{without} partition constraints --- the global model
--- define the spatial influence of agent~$j$ on agent~$i$:
\begin{equation}
    D_{i\leftarrow j}(F)
    = \sum_{a,k}
    \left|\frac{\partial F_{i,a}}{\partial X_{j,k}}\right|
    \label{eq:djac}
\end{equation}
where $X_{j,k}$ is feature~$k$ of agent~$j$'s observation and $F_{i,a}$ is
output dimension~$a$ at agent~$i$.
The \emph{global-model restriction} is essential: in a partitioned model,
cross-module inputs are absent by construction, making cross-module Jacobians
identically zero --- a structural artefact, not evidence of low dependency.
We instantiate Eq.~\eqref{eq:djac} at two levels:
\begin{align}
    D^{Q}_{i\leftarrow j}
     & = D_{i\leftarrow j}(V^{\mathrm{global}})
     &                                                         & \text{(global MAPPO critic, L2)}
    \label{eq:dq}                                                                                          \\
    D^{G}_{i\leftarrow j}
     & = D_{i\leftarrow j}(\mathbf{h}^{(L),\mathrm{global}}_i)
     &                                                         & \text{(global CoLight GAT embedding, L3)}
    \label{eq:dg}
\end{align}
Whereas \citet{lrd2025} use Jacobian profiles to ask whether a GNN suffers
from over-squashing, we use the same instrument to ask whether a proposed partition
aligns with what the model has learned to depend on --- a distinct scientific question.

\paragraph{Hop-distance profile.}
For either instrument, aggregate dependency by road-graph hop distance $\rho(i,j)$:
\begin{equation}
    \bar{D}_h
    = \frac{1}{|\mathcal{V}|}\sum_{i}\sum_{j:\,\rho(i,j)=h} D_{i\leftarrow j}
    \label{eq:barDh}
\end{equation}
This is the MARL analogue of the per-hop influence profile $\bar{T}_h$
of~\citet{lrd2025}: $\bar{D}_h$ quantifies the average spatial dependency
from agents exactly $h$ road-graph hops away, and its decay rate determines
the minimum module radius needed for effective coordination.

\paragraph{Dependency retention ratio $\Psi$.}
Given dependency matrix $\mathbf{D}$ and partition $\mathcal{P}=\{P_1,\ldots,P_K\}$:
\begin{equation}
    \Psi(\mathcal{P},\,\mathbf{D})
    = \frac{\displaystyle\sum_{k}\sum_{i,j\,\in\, P_k} D_{ij}}
    {\displaystyle\sum_{i,j} D_{ij}}
    \label{eq:psi}
\end{equation}
$\Psi \in [0,1]$ is the \emph{dependency retention ratio}: the fraction of total
inter-agent dependency captured within module boundaries.
High $\Psi$ means the partition cuts predominantly low-dependency edges ---
preserving coordination capacity --- while low $\Psi$ means high-dependency edges
are severed, imposing coordination cost.

\paragraph{Relation to existing partition quality metrics.}
Graph modularity $Q$~\citep{newmangirvan2004} and normalised
cut~\citep{shimalik2000} are the standard partition quality metrics.
$\Psi$ differs from both in two respects.
First, $\Psi$ requires no null model: $\mathbf{D}$ is already a semantically
meaningful quantity (MI or Jacobian sensitivity), not raw structural adjacency
for which a random-graph null is appropriate.
Second, $\mathbf{D}$ is asymmetric and non-negative (direction matters: agent $j$
influences $i$ via traffic flow), whereas $Q$ and normalised cut assume undirected
graphs.
By computing $\Psi(\mathcal{P}_{\mathrm{InfoMap}},\mathbf{D})$ vs.\
$\Psi(\mathcal{P}_{\mathrm{METIS}},\mathbf{D})$ on the \emph{same} $\mathbf{D}$,
we obtain a direct, architecture-independent measure of which partition better
preserves the inter-agent dependency structure.

\paragraph{Size-adjusted retention and partition-level significance.}
Raw $\Psi$ is biased toward coarse partitions: larger modules retain more of
any $\mathbf{D}$ simply by cutting fewer pairs.
We therefore report, alongside $\Psi$, the chance-adjusted score
\begin{equation}
    \Psi_{\mathrm{adj}}(\mathcal{P}, \mathbf{D})
    = \frac{\Psi(\mathcal{P}, \mathbf{D})
        - \mathbb{E}_{\mathcal{P}' \sim \mathcal{R}(\mathcal{P})}
        \!\left[\Psi(\mathcal{P}', \mathbf{D})\right]}
    {1 - \mathbb{E}_{\mathcal{P}' \sim \mathcal{R}(\mathcal{P})}
        \!\left[\Psi(\mathcal{P}', \mathbf{D})\right]},
    \label{eq:psiadj}
\end{equation}
where $\mathcal{R}(\mathcal{P})$ draws random partitions with the same
module-size sequence as $\mathcal{P}$.
$\Psi_{\mathrm{adj}}$ measures the excess dependency retained beyond
size-matched chance, in the spirit of chance-adjusted clustering-comparison
scores, and makes partitions with different module-size profiles comparable.
The same null supplies the partition-level significance test we use in place
of pairwise hypothesis tests: holding $\mathbf{D}$ fixed, sample size-matched
random partitions and report the percentile of the candidate partition's
within-module mass $\sum_{c(i)=c(j)} D_{ij}$ under this null.
This yields one well-powered statistic per (network, $K$, seed) instead of
hundreds of noisy pairwise estimates --- the test the theory of
Section~\ref{sec:transfer} actually licenses.

\subsection{From Flow to Dependency: A Transfer Lemma}
\label{sec:transfer}

The second link of the chain connects the flow a partition retains
(Proposition~\ref{prop:phi}) to the dependency it retains
(Section~\ref{sec:psi}).
The claim is a stylised-model bound, stated under explicit assumptions on the
traffic dynamics; it is a property of flow-local traffic networks, not of
arbitrary multi-agent systems.

\begin{assumption}[Flow-local dynamics]
    \label{ass:local}
    The traffic state evolves as a Markov chain whose transition kernel
    factorises over the road graph: $X_i(t{+}1)$ depends only on
    $\{X_j(t) : j \in \mathcal{N}(i) \cup \{i\}\}$ and exogenous demand
    $\xi(t)$, as in cell-transmission and link-queue
    models~\citep{daganzo1994ctm,jin2012linkqueue}.
\end{assumption}

\begin{assumption}[Flow-bounded coupling]
    \label{ass:coupling}
    One-step inter-intersection coupling is bounded proportionally to the flow
    exchanged: there exists a constant $\alpha$ (a function of link capacities
    and saturation rates) such that the Dobrushin-style influence coefficient
    obeys
    $C_{j \leftarrow i} \leq \alpha \, (W_{ij} + W_{ji}) + \beta_{ij}$,
    where $\beta_{ij}$ collects coupling through common exogenous demand.
    The two flow terms are the two physical transmission channels of traffic:
    the \emph{forward (arrival) channel} --- downstream queue state depends on
    upstream state only through the vehicles actually routed between them ---
    and the \emph{backward (blocking) channel} --- finite link capacity
    throttles upstream senders in proportion to their sending flow when
    downstream space runs out~\citep{daganzo1994ctm,jin2012linkqueue}, i.e.\
    spill-back propagates on the reverse flow graph.
\end{assumption}

\begin{assumption}[Regime stationarity]
    \label{ass:stationary}
    Demand statistics are stationary over the measurement window, so
    $\mathbf{W}$ and $\mathbf{D}$ are estimated within a single traffic regime.
\end{assumption}

\begin{proposition}[Cut flow upper-bounds cut dependency]
    \label{prop:transfer}
    Under Assumptions~\ref{ass:local}--\ref{ass:stationary}, the dependency
    mass cut by a partition is bounded by the flow it cuts: there exist
    $\kappa > 0$ and a demand-confounder term
    $\epsilon_{\mathrm{dem}} \geq 0$ such that
    \begin{equation}
        1 - \Psi(\mathcal{P}, \mathbf{D})
        \;\leq\;
        \kappa \left(1 - \Phi(\mathcal{P}, \widetilde{\mathbf{W}})\right)
        + \epsilon_{\mathrm{dem}},
        \label{eq:transfer}
    \end{equation}
    where $\widetilde{W}_{ij} = W_{ij} + W_{ji}$ is the symmetrised flow,
    $\kappa$ absorbs $\alpha$ and the normalisations of $\mathbf{D}$ and
    $\widetilde{\mathbf{W}}$, and $\epsilon_{\mathrm{dem}}$ aggregates the
    common-demand terms $\beta_{ij}$ across the cut.
\end{proposition}

A proof sketch --- a one-step entrywise bound followed by a
path-composition/data-processing argument for longer lags --- is given in
Appendix~\ref{app:proofs}.
The direction of the bound matters: low cut flow certifies low cut dependency,
but high $\Psi$ does not certify high performance --- the bound is necessary-,
not sufficient-, for lossless decomposition.
The constant $\kappa$ and the confounder $\epsilon_{\mathrm{dem}}$ are
network- and regime-dependent; the experiments estimate them rather than
assume them away.

\paragraph{H1 and H2 as operational signatures.}
Proposition~\ref{prop:transfer}'s two channels yield two testable empirical
signatures, which earlier iterations of this work treated as a mandatory
pre-training gate.
The theory clarifies their correct epistemic status: they are
\emph{corollaries in expectation} of the transfer bound --- diagnostics that
the mechanism is active --- not axioms the method depends on.
We report both as supporting evidence; failure on a given network localises
which channel is inactive there, rather than invalidating the partition.

\medskip
\noindent\textbf{H1 (Spatial MI Advantage --- forward-channel signature).}
Within-module agent pairs share higher mutual information about future traffic
states than cross-module pairs:
\begin{equation}
    \mathbb{E}_{i,j\in M_k}\!\left[I(X_i(t);\, X_j(t{+}\tau))\right]
    >
    \mathbb{E}_{i\in M_k,\, l\notin M_k}\!\left[I(X_i(t);\, X_l(t{+}\tau))\right]
    \label{eq:h1}
\end{equation}
averaged over propagation lags $\tau \in \{1, 5, 15, 30\}$ steps, with MI
estimated by the KSG estimator~\citep{kraskov2004ksg} and visualised as a
$|\mathcal{V}|\times|\mathcal{V}|$ heatmap with module boundaries overlaid.
Note what the theory does and does not predict here:
Proposition~\ref{prop:transfer} bounds \emph{aggregate} cut dependency mass,
not the ordering of every individual pair $(i, j, l)$.
A uniform pairwise test --- e.g.\ a Wilcoxon signed-rank test over all pairs
--- therefore tests a strictly stronger claim than the theory makes, and
marginal pairwise pass rates are expected rather than anomalous.
The theory-matched test is the partition-level permutation test of
Section~\ref{sec:psi}.

\medskip
\noindent\textbf{H2 (Spill-back Containment --- backward-channel signature).}
Spill-back congestion is more likely to remain within InfoMap modules than to
cross module boundaries:
\begin{equation}
    \Pr\!\left(\text{spill-back}_{i\to j}
    \;\middle|\; i,j \in M_k\right)
    >
    \Pr\!\left(\text{spill-back}_{i\to l}
    \;\middle|\; i \in M_k,\; l \notin M_k\right),
    \label{eq:h2}
\end{equation}
assessed via a proportion test on SUMO queue trajectory data.
\citet{dependencydyn2025} establish that inter-agent coordination is necessary
\emph{if and only if} spill-back connects two agents' queues.
The apparent directional asymmetry --- OD flow travels $i \to j$ (forward)
while spill-back propagates $j \to i$ (backward) --- is precisely the
two-channel structure of Assumption~\ref{ass:coupling}: a high-volume corridor
$W_{ij}$ drives high arrival rates at $j$ which, under near-saturated demand,
trigger backward-propagating queue waves toward $i$~\citep{dependencydyn2025}.
The coordination-necessary pair and the high-OD-flow pair are thus the same
pair on the same corridor.
Crucially, the backward channel is active \emph{only near saturation}: in a
network or demand regime that never leaves free flow, spill-back events are
absent, the backward channel is inert, and all measured dependency is
arrival-driven.
An empty H2 test on such a network is a statement about the regime, not a
refutation of the mechanism.

\medskip
\noindent\textbf{Why containment, not just correlation, matters.}
Spill-back containment has a formal interpretation beyond the statistical test
above.
In the Lyapunov-drift framework for constrained queueing
networks~\citep{tassiulas1992stability}, a decentralised scheduler preserves
the stability region of a centralised one only if it can react to the joint
queue state of servers whose queues are dynamically coupled; max-pressure
signal control~\citep{varaiya2013maxpressure} instantiates exactly this drift
argument for signalised intersections via a quadratic Lyapunov function over
per-approach queue lengths.
Read against that framework, H2 states the condition under which cutting a
coordination-graph edge is safe: an edge can be severed without sacrificing
the stability that joint observation would provide only if spill-back across
it is rare.
We do not derive a stability guarantee for the learned MARL policies studied
here; we invoke this literature as the control-theoretic motivation for
treating spill-back rate, rather than mutual information alone, as the
quantity that determines which edges a partition may safely cut.

\paragraph{The demand confounder.}
The term $\epsilon_{\mathrm{dem}}$ in Eq.~\eqref{eq:transfer} is not a
formality.
Network-wide demand fluctuations act as a common cause, creating mutual
information between intersections that exchange \emph{no} flow, and this
common-cause mass grows with network size --- predicting that the raw
alignment between $\mathbf{W}$ and $D^{\mathrm{MI}}$ weakens on larger
networks even when the flow-borne coupling is unchanged.
The theory-driven fix is to estimate $D^{\mathrm{MI}}$ \emph{conditionally}
on an aggregate demand covariate (e.g.\ total network occupancy at time $t$),
which removes the common-cause channel by construction.
Model-derived instruments such as $D^{G}$ (Section~\ref{sec:psi}) largely do
not inherit the confounder: a trained model has no incentive to route
gradient through agents that carry no decision-relevant information.

\subsection{From Dependency Retention to Regional Value Loss}
\label{sec:valueloss}

The third link imports value-loss bounds from networked MARL and
influence-based abstraction, conditional on the coupling structure established
by Proposition~\ref{prop:transfer}.
In networked MARL, when one-step influence is local, the sensitivity of one
agent's value to another decays exponentially with graph distance, and
policies truncated to an $r$-hop neighbourhood approximate the global optimum
with bias decaying exponentially in
$r$~\citep{qu2022scalable,qu2020average};
recent work replaces the classical row-sum (Dobrushin) condition for this
locality with a weaker, policy-dependent spectral certificate
$\rho(H^{\pi}) < 1$~\citep{chakraborty2026locality}.
Influence-based abstraction bounds the value loss of a local model by the
error of its representation of the influence the rest of the system exerts on
it~\citep{congeduti2021iba}.
A regional decomposition is exactly such a truncation: each module models
within-module influence and ignores the rest, so the discarded influence is
the cut dependency mass.

\begin{theorem}[Regional value loss is controlled by cut dependency; informal]
    \label{thm:valueloss}
    Let $J^{\star}$ denote optimal global coordination performance and
    $J_{\mathcal{P}}$ the performance of regional MARL under partition
    $\mathcal{P}$.
    Under Assumptions~\ref{ass:local}--\ref{ass:coupling} and either the
    value-locality conditions of \citet{qu2022scalable} or the
    approximate-influence conditions of \citet{congeduti2021iba}, there exists
    $C > 0$ such that
    \begin{equation}
        J^{\star} - J_{\mathcal{P}}
        \;\leq\;
        C \left(1 - \Psi(\mathcal{P}, \mathbf{D})\right)
        + \epsilon_{\mathrm{approx}} + \epsilon_{\mathrm{opt}},
        \label{eq:valueloss}
    \end{equation}
    where $\epsilon_{\mathrm{approx}}$ and $\epsilon_{\mathrm{opt}}$ are
    function-approximation and optimisation errors, neither of which the
    partition controls.
    Chaining Eqs.~\eqref{eq:qphi}, \eqref{eq:transfer}, and
    \eqref{eq:valueloss}: \emph{minimising the map equation minimises an upper
        bound on the value loss of regional decomposition in MARL}.
\end{theorem}

Derivation notes are given in Appendix~\ref{app:proofs}; the theorem imports
its heavy machinery from \citet{qu2022scalable} and \citet{congeduti2021iba}
and our contribution is the construction that connects them to OD flow via
Propositions~\ref{prop:phi} and~\ref{prop:transfer}.
Three caveats bound the claim's scope.
The bound is one-directional: high retention is (approximately) necessary for
lossless regional decomposition, not sufficient, and METIS also retains
substantial flow --- the theory predicts orderings and bounds, not that
InfoMap is optimal for $J$.
The constants are network- and regime-dependent.
And $\epsilon_{\mathrm{opt}}$ can dominate in practice: the theory predicts
performance \emph{trends} across partitions, not guaranteed outcomes of any
single training run.

\paragraph{Per-level reading.}
Theorem~\ref{thm:valueloss} specialises differently at each coordination
coupling level of Section~\ref{sec:levels}, yielding level-specific
predictions.
\emph{L1 (regional reward).} A shared regional reward is a surrogate for each
agent's own reward whose bias grows with within-module outcome
\emph{misalignment}; the forward channel ties alignment to flow coherence, so
the flow partition should help most where reward coupling is rawest.
\emph{L2 (regional critic).} The regional critic is precisely the local model
of influence-based abstraction: its approximation loss is bounded by the
influence it ignores, i.e.\ the cut dependency~\citep{congeduti2021iba}.
\emph{L3 (attention masking).} The truncation bound carries a second term
that grows once modules shrink below the influence-decay length: masking then
removes edges the decay argument still needs.
This predicts a \emph{phase boundary} in the module count $K$: below it,
flow-coherent partitions win; above it, the truncation term dominates and
geometrically compact partitions can win, with the reversal point shifting
with network size and demand level.
Section~\ref{sec:experiments} tests this as a prediction rather than treating
any observed reversal as an anomaly.

\subsection{Coordination Coupling Spectrum}
\label{sec:levels}

We evaluate the InfoMap partition across three coordination coupling levels,
using established MARL algorithms as probes. The partition is held fixed across
all three; only the coordination mechanism varies.
This design isolates the partition's contribution from algorithm-specific effects,
and tests whether the dependency retention advantage of InfoMap is
architecture-agnostic. IDQN, also compatible in principle with L1's reward-averaging
mechanism, is deferred from the main results pending further investigation into
an observed failure mode under regional reward averaging (Appendix~\ref{app:results}).

\noindent\textbf{Operational predictions.}
The following are the primary empirical targets of our experimental design,
instances of the retention chain
(Propositions~\ref{prop:phi} and~\ref{prop:transfer},
Theorem~\ref{thm:valueloss}) at each coupling level:
\begin{description}
    \item[\textbf{OP1 (L1):}]
          $\Psi(\mathcal{P}_{\mathrm{InfoMap}}, D^{\mathrm{MI}}) >
              \Psi(\mathcal{P}_{\mathrm{METIS}}, D^{\mathrm{MI}})$.
          Within-module reward averaging operates on correlated signals, reducing
          gradient noise and training instability.
    \item[\textbf{OP2 (L2):}]
          $\Psi(\mathcal{P}_{\mathrm{InfoMap}}, D^{Q}) >
              \Psi(\mathcal{P}_{\mathrm{METIS}}, D^{Q})$.
          The regional critic captures dominant value dependencies without modelling
          irrelevant cross-module states, reducing credit-assignment variance.
    \item[\textbf{OP3 (L3):}]
          $\Psi(\mathcal{P}_{\mathrm{InfoMap}}, D^{G}) >
              \Psi(\mathcal{P}_{\mathrm{METIS}}, D^{G})$, observed via a lower
          influence-weighted attention range $\hat{\rho}_u$ for regional vs.\ global
          CoLight (Section~\ref{sec:attnrange}), provided module size is
          sufficient (${\geq}4$ agents per module).
\end{description}

\noindent The three OPs together constitute \textbf{Hypothesis H}: an InfoMap
partition achieves higher $\Psi$ than METIS across the three dependency
instruments, and --- per the monotone bound of Theorem~\ref{thm:valueloss} ---
this advantage predicts better task-performance trends at each coupling level,
\emph{subject to} the L3 module-size phase boundary identified in
Section~\ref{sec:valueloss}.
The qualifier is load-bearing, not decorative: Section~\ref{sec:experiments}
reports a $\Psi(D^{G})$ reversal at the coarser tested module count on both
networks, which OP3's own phase-boundary clause predicts rather than
contradicts, while OP1 and OP2 hold in every same-$k$ comparison tested.

\subsection{Setup}
\label{sec:setup}
We evaluate on two real-world SUMO road networks of different scale:
Cologne8 (8 signalised intersections, 30-dimensional per-agent state) and
Ingolstadt21 (21 signalised intersections, 85-dimensional per-agent state).
For each network we construct an InfoMap partition and a METIS partition at
matched module count~$k$, plus a no-partition (global/local) baseline, and
hold the partition fixed while varying the coordination mechanism across the
three coupling levels of Section~\ref{sec:levels}: IPPO (L1), MAPPO (L2), and
CoLight (L3), with IDQN deferred per Section~\ref{sec:levels}.
$D^{\mathrm{MI}}$ is estimated by the KSG estimator~\citep{kraskov2004ksg}

$D^{G}$ is the Jacobian instrument of Eq.~\eqref{eq:dg} evaluated on one
seed-7 global (no-partition) CoLight checkpoint per network, and therefore
carries no across-seed uncertainty estimate.
Downstream training results are single-seed (seed~0, 1,500 episodes each),
reported here as a case study rather than a statistically powered comparison;
we state this scope explicitly rather than invoking rliable-style IQM and
bootstrap confidence intervals~\citep{agarwal2021rliable} over data we do not
have, in line with the standard of evidence Henderson et al.\
argue RL results should be held to~\citep{henderson2018matters}.
We therefore split the evaluation into two parts: retention diagnostics
(Sections~\ref{sec:exp-phi}--\ref{sec:exp-dg}), which are multi-seed and
constitute the paper's confirmatory evidence, and downstream training
performance (Sections~\ref{sec:exp-perf}--\ref{sec:attnrange}), which is
single-seed and descriptive.

\subsection{Spill-Back Diagnostic (H2)}
\label{sec:exp-h2}

H2 is inconclusive with the available data.
Ingolstadt21 produced 1 spill-back event in seed~0, 2 in seed~1, and none in

small to test the claim either way, and we report this as a genuine gap
rather than folding it into the headline evidence.
The random baseline (Section~\ref{sec:exp-phi}) does not change this picture:
Cologne8 again has zero events, and no random-partition/seed combination on
Ingolstadt21 passes H2 ($p \in [0.0857, 1.0]$ where events exist).
The sparsity is therefore a property of the demand regime, not an artefact of
which partition is tested.

\subsection{Scope of Ablations}
\label{sec:exp-ablations}

The module-count sweep ($k \in \{3,5\}$ on Cologne8, $k \in \{4,5\}$ on

are the ablations this paper's evidence supports; together they answer
whether the InfoMap advantage survives varying granularity and whether it
reflects flow-coherence specifically rather than the mere presence of module
boundaries.
The random partition reported here is a single size-balanced round-robin

multiple random seeds; a degree-matched variant and a reward-annealing
schedule ablation remain unrun in the data available for this draft.
We do not report simulated or projected numbers for either, and list both
explicitly as future work in Section~\ref{sec:conclusion} rather than
omitting them silently.

\section{Proof Sketches and Derivation Notes}
\label{app:proofs}

\subsection{Proposition~\ref{prop:phi}}
\label{app:proofs:phi}

With the empirical OD walk, the stationary probability of traversing the
directed edge $(i, j)$ in one step is
$p_i \, p_{ij} = \frac{\sum_b W_{ib}}{\sum_{a,b} W_{ab}} \cdot
    \frac{W_{ij}}{\sum_{b} W_{ib}} = \frac{W_{ij}}{\sum_{a,b} W_{ab}}$.
The aggregate inter-module rate is the total stationary probability of steps
whose endpoints lie in different modules,
$q_{\circlearrowleft} = \sum_{i,j:\, c(i) \neq c(j)} p_i \, p_{ij}
    = \big(\sum_{i,j:\, c(i) \neq c(j)} W_{ij}\big) / \sum_{a,b} W_{ab}$,
which is $1 - \Phi(\mathcal{P}, \mathbf{W})$ by Eq.~\eqref{eq:phi}.
\hfill$\square$

\subsection{Proposition~\ref{prop:transfer} (sketch)}
\label{app:proofs:transfer}

\emph{Step 1 (one-step bound).}
Under Assumption~\ref{ass:local} the transition kernel factorises over the
road graph, so any one-step statistical dependency between the states of
intersections $i$ and $j$ is mediated by the coupling coefficients of
Assumption~\ref{ass:coupling}.
For lag $\tau = 1$, each entry of the dependency matrix is bounded entrywise,
$D_{ij} \leq \alpha' \widetilde{W}_{ij} + \beta_{ij}$, where $\alpha'$ absorbs
$\alpha$ and the scale of the instrument (for $D^{\mathrm{MI}}$, via the
standard relation between influence coefficients and mutual information under
bounded state spaces).
Summing over cut pairs,
$\sum_{c(i) \neq c(j)} D_{ij}
    \leq \alpha' \sum_{c(i) \neq c(j)} \widetilde{W}_{ij}
    + \sum_{c(i) \neq c(j)} \beta_{ij}$.

\emph{Step 2 (path composition).}
For lags $\tau > 1$, dependency between $i$ and $j$ is generated along
directed paths $i \to \cdots \to j$ in the coupling graph.
By a data-processing argument, each path contributes at most the product of
its one-step couplings; every path connecting a cut pair crosses the boundary
at some step, so its contribution is bounded by a cut-edge flow term
multiplied by sub-unit within-module coupling factors.
Summing the resulting geometric series (finite under
Assumption~\ref{ass:coupling} with bounded total coupling) inflates $\alpha'$
by a constant but preserves the form of the bound.

\emph{Step 3 (normalisation).}
Dividing by the total dependency mass $\sum_{i,j} D_{ij}$ and by
$\sum_{i,j} \widetilde{W}_{ij}$ yields Eq.~\eqref{eq:transfer}, with $\kappa$
collecting the constants of Steps~1--2 and $\epsilon_{\mathrm{dem}}$ the
normalised common-demand mass across the cut.

\emph{Honesty notes.}
$\kappa$ is network- and regime-dependent; Assumption~\ref{ass:stationary}
matters because pooling across regimes mixes coupling structures with
different constants.
$\epsilon_{\mathrm{dem}}$ is not small in general and grows with network size;
when it dominates, the bound is uninformative --- which is detectable, and
correctable by estimating $\mathbf{D}$ conditionally on an aggregate demand
covariate (Section~\ref{sec:transfer}).

\subsection{Theorem~\ref{thm:valueloss} (derivation notes)}
\label{app:proofs:valueloss}

Two independent routes give the stated shape; we import both rather than
re-derive them.
\emph{Exponential-decay route.}
Assumption~\ref{ass:coupling} bounds one-step influence entrywise; under the
$(c, \rho)$-exponential-decay conditions of \citet{qu2022scalable} (or the
policy-dependent spectral certificate $\rho(H^{\pi}) < 1$ of
\citet{chakraborty2026locality}, which weakens the row-sum condition), the
sensitivity of agent $i$'s value to agent $j$ decays exponentially in graph
distance, and truncating each agent's policy/value dependence to its module is
an approximation whose bias is bounded by the discarded influence mass ---
which is, by construction, the cut dependency that $1 - \Psi$ measures.
\emph{Influence-based-abstraction route.}
A regional critic is a local model that approximates (or ignores) the
influence sources outside its module; \citet{congeduti2021iba} bound the value
loss of such a model by its influence-approximation error, which the cut
dependency mass upper-bounds.
The $\epsilon_{\mathrm{approx}}$ and $\epsilon_{\mathrm{opt}}$ terms isolate
neural-approximation and training effects that the partition does not
control; they are why the theorem predicts trends across partitions rather
than outcomes of single runs.

\section{Algorithm: InfoMap Coordination Graph Construction}
\label{app:algorithm}

H1 and H2 are \emph{operational signatures} of the transfer bound
(Section~\ref{sec:transfer}), not engineering controls.
The algorithm always returns the InfoMap partition; the signature results are
reported as supporting evidence and logged for transparency.
A failure on a given network localises which transmission channel is inactive
there (e.g.\ an all-free-flow regime yields no spill-back events, so the
backward channel is inert) and is reported separately.

\begin{algorithm}[H]
    \caption{Flow-coherent coordination graph construction with dependency verification}
    \label{alg:infomap}
    \begin{algorithmic}[1]
        \Require Traffic network $\mathcal{G} = (\mathcal{V}, \mathcal{E})$,
        number of modules $K$, warm-up steps $T_w$
        \Ensure  Partition $\mathcal{M} = \{M_1, \ldots, M_K\}$,\;
        dependency matrix $\mathbf{D}^{\mathrm{MI}}$,\;
        verification results $(p_{\mathrm{H1}},\, p_{\mathrm{H2}})$
        \State Run $T_w$ steps under a uniformly random policy; log all vehicle trips
        \State Construct $\mathbf{W}$: $\;W_{ij} \leftarrow$ vehicle count $i \to j$
        \State Apply Infomap to $\mathcal{G}_{\mathrm{OD}} = (\mathcal{V}, \mathcal{E}, \mathbf{W})$
        $\;\Rightarrow\;$ partition $\mathcal{M} = \{M_1,\ldots,M_K\}$
        \State Estimate $D^{\mathrm{MI}}_{ij}$ via KSG estimator~\citep{kraskov2004ksg}
        at $\tau \in \{1,5,15,30\}$ steps
        \Statex \hspace{1em}\textit{// H2 signature check (backward channel)}
        \State Extract spill-back events from SUMO queue trajectories
        \State Compute within-module and cross-module spill-back proportions;
        run one-sample proportion test $\;\Rightarrow\; p_{\mathrm{H2}}$
        \Statex \hspace{1em}\textit{// H1 signature check (forward channel)}
        \State Classify agent pairs as within-module or cross-module under $\mathcal{M}$
        \State Compare $D^{\mathrm{MI}}_{ij}$ distributions;
        run Wilcoxon signed-rank test $\;\Rightarrow\; p_{\mathrm{H1}}$
        \State \textbf{Report} $(p_{\mathrm{H1}},\, p_{\mathrm{H2}})$;
        generate MI heatmap with module boundaries (Fig.~2 in main text)
        \State \Return $\mathcal{M}$,\; $\mathbf{D}^{\mathrm{MI}}$,\;
        $(p_{\mathrm{H1}},\, p_{\mathrm{H2}})$
    \end{algorithmic}
\end{algorithm}

\section{Regional MARL Architecture}
\label{app:arch}

All three coordination levels share a common regional infrastructure.
Partition assignments are stored in \texttt{cfg.management} (one list of
agent IDs per module), which is populated from the InfoMap or METIS output
before any training begins.
A central helper module (\texttt{agents/common/marl.py}) provides
\texttt{transform\_reward\_array(scope, rewards, cfg)} --- supporting
\texttt{local}, \texttt{global\_mean}, and \texttt{regional\_mean} scopes ---
and \texttt{CentralizedInputBuilder}, which assembles critic observations for
\texttt{global}, \texttt{regional}, or \texttt{local} scopes and zero-pads
uneven regional input sizes to a common dimension.

\subsection{L1 --- Regional Reward (IPPO)}
\label{app:arch:ippo}

Regional IPPO applies flow-partition structure at the reward level only.
Each agent maintains an independent local actor-critic PPO learner
(\texttt{agents/policy/pfrl\_ppo.py}); there is no cross-agent parameter
sharing or communication.
Before each learner's \texttt{observe()} call, individual scalar rewards
are passed through \texttt{transform\_reward\_array} with
\texttt{reward\_scope: regional\_mean}, replacing each agent's reward with
the arithmetic mean of rewards within its InfoMap module.
Unassigned agents (singletons not covered by \texttt{cfg.management}) retain
their individual reward.
The default configuration (\texttt{config/agent.yaml}) sets
\texttt{reward\_scope: local}; regional behaviour is enabled by
\texttt{reward\_scope: regional\_mean}.
IDQN (\texttt{agents/action\_value/pfrl\_dqn.py}) follows the identical
reward-rewriting path.

\paragraph{Mechanism.}
Regional averaging reduces credit-assignment noise when agents within the
same module experience correlated outcomes (high $D^{\mathrm{MI}}$).
It is harmful when modules group uncorrelated agents, because the averaged
signal is less informative than the individual reward.
This makes IPPO performance at L1 a direct diagnostic of partition quality.

\subsection{L2 --- Regional Critic (MAPPO)}
\label{app:arch:mappo}

MAPPO is implemented in \texttt{agents/policy/actor\_critic.py} on top of
\texttt{ActorCriticBase}.
Actors use local observations and mask invalid actions for heterogeneous
action spaces (shared actor-network weights across agents).
The critic input is assembled by \texttt{CentralizedInputBuilder} under
\texttt{critic\_scope: regional}: each agent's critic receives the concatenated
observations of all agents in its InfoMap module, zero-padded to the maximum
regional size.
Reward sharing is controlled separately via \texttt{reward\_scope}; the
standard regional MAPPO configuration uses both
\texttt{critic\_scope: regional} and \texttt{reward\_scope: regional\_mean}.

Global MAPPO (\texttt{critic\_scope: global}) feeds all $N$ agents'
observations to a single shared critic.
For $N = 21$ (Ingolstadt21), the global critic input dimension is $21 \times
    d_{\mathrm{obs}}$, making it substantially harder to train than a regional
critic of dimension $|M_k| \times d_{\mathrm{obs}}$ where $|M_k| \approx 4$--$5$.

\paragraph{Mechanism.}
The regional critic captures dominant value dependencies
($D^Q_{i\leftarrow j}$ high within module) without modelling irrelevant
cross-module states, reducing critic approximation error and policy-gradient
variance.
On networks where a global critic is impractical (large $N$), regional InfoMap
critics can \emph{outperform} global CTDE, as observed on Ingolstadt21.

\subsection{L3 --- Regional Attention (CoLight)}
\label{app:arch:colight}

CoLight is implemented in \texttt{agents/action\_value/colight.py}.
The topology is built from \texttt{signal.yaml} downstream links as
bidirectional graph edges.
Two distinct regional variants exist; they test different scientific questions.

\paragraph{Variant A: PartitionedAttentionStack.}
Enabled by \texttt{colight\_partitioned\_message\_passing: True}.
One GAT attention stack per module is created; all stacks share the same
underlying network weights and a single replay buffer.
Attention is structurally restricted to within-module edges --- agents in
different modules cannot attend to each other.
This is the correct variant for testing whether InfoMap topology improves
the quality of \emph{communication}, as the learned $D^G$ Jacobians are
computed on a globally-unified model but message-passing is constrained.

\paragraph{Variant B: CoLightRegional.}
Separate agent class that instantiates one independent
\texttt{\_CoLightRegionLearner} per partition.
Each regional learner has its own CoLight network, target network, optimizer,
replay buffer, action mask, regional edge index, and $\epsilon$-schedule.
\texttt{CoLightRegional.observe()} converts individual rewards to the mean
reward within each region before inserting transitions into that region's
replay buffer.
This variant tests whether divide-and-conquer training by region is beneficial;
it is \emph{not} equivalent to restricting communication in a global model.
When module size is small ($|M_k| \lesssim 3$), Variant B creates highly
under-sampled regional learners with unstable target networks.

\paragraph{Fallback.}
If \texttt{cfg.management} is absent, both variants fall back to one global
region covering all agents.
